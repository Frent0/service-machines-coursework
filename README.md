# Service Machines

Курсовой проект: информационная система для технического обслуживания станков.

Стек: Java 21, JavaFX 21, MySQL, Hibernate ORM, Maven.

Открыть `pom.xml` в IntelliJ IDEA как Maven project.
В `src/main/resources/hibernate.cfg.xml` заменить `CHANGE_ME` на пароль MySQL.
База `service_machines` должна быть создана заранее.
Запуск: `mvn javafx:run`.

Это стартовый каркас. Следом добавляются сущности, Repository, MVC Controller/View, авторизация и CRUD.
